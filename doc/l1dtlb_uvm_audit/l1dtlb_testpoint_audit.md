## 1. Audit Basis

This audit treats `l1dtlb_function_description.md` as the highest-priority L1DTLB functional specification. The current plan and UVM sources checked are:

- `doc/MMU_VerificationPlan_final.md`
- `doc/section6_3_lsu_l1dtlb_l2tlb_tlbop_baseline_tc.md`
- `mmu_verification/testbench/test/l1dtlb_tests/*.svh`
- `mmu_verification/testbench/test/phase9_common/phase9_generated_test_base.svh`
- `mmu_verification/testbench/lsu_agent/lsu_sequences.svh`

- Existing observable checks in `mmu_translation_sb`, `mmu_credit_sb`, LSU covergroups, whitebox covergroups, and top-level probes.

The audit table is requirement-driven: each row is keyed by a L1DTLB function/requirement item, not by a coverage item. `Current Status` uses the vocabulary defined in the spec: `keep`, `modify`, `add`, `delete`, `split`, `merge`, `unclear`.

Existing check capability:

- `mmu_translation_sb` can check LSU pipe0/pipe1 PA/fault outcomes and has a DTLB exception-CAM shadow, but it also waives several expt-CAM timing details.
- `mmu_credit_sb` tracks external outstanding requests and end-of-test drain. It is not an exact L1DTLB scheduler credit counter checker.
- `mmu_env_cg_whitebox::cg_l1dtlb` only samples MB occupancy bins `0`, `1..3`, `4..7` and MB0 FSM state. It does not cover MB full=8, all entries, or transitions.
- LSU covergroups sample pipe operation, abort, `pa_vld`, `page_fault`, and `access_fault`, but do not cross with `tlb_busy`, `tlb_wakeup`, expt-CAM match, or T0/T1 ownership.
- `tb_top.sv` exposes many useful L1D probes, including pipe hit/miss, refill, entry update, MB valid/state, and expt-CAM writes. These probes are enough to add the missing SVA/coverage later.

## 4. Recommended Action Summary

Keep:

- Keep `DTLB_HIT_001` and `DTLB_HIT_002` as basic pipe0/pipe1 smoke tests.
- Keep the existing invalidate, abort, refill, MB, credit, STAMO, and PLRU wrappers as traceability shells for now.

Modify:

- Modify `DTLB_PERM_*` tests to build the required PTE permissions instead of using generic `lsu_st_ld_mix_seq`.
- Modify `DTLB_PERM_ST_002` expected behavior: D-bit missing should be a store page fault/no hardware writeback, not a D-bit update test.
- Modify `DTLB_INV_003` expected behavior for L1DTLB: ASID-related L1 invalidation should full-clear because L1DTLB entries do not store ASID.
- Modify `DTLB_PLRU_001`: remove black-box exact victim expectation; retain as whitebox PLRU coverage/SVA only.
- Modify `DTLB_BUSY_ANY_INFLIGHT_001` plan text so the stimulus is "any MB entry valid", not "MB full".

Add:

- Directed dual-pipe tests: same-cycle hit/hit, hit/miss, same-4K miss dedup, different-4K dual allocate, one-free-entry IID-age arbitration including wrap.
- Directed MB/scheduler tests: MB full drop, MB CAM hit no allocation/no wakeup, credit=0 plus same-cycle return no-fire, credit>0 return+fire conservation, one-request-per-cycle, old MB priority over bypass, bypass IDLE->WFC.

- Directed invalidation races after spec clarification: invalidate+hit and invalidate+install.
- Directed STAMO pipe1 negative test and MMU-off/machine-mode direct-map test.
- Coverage/SVA additions for busy/wakeup broadcast, T0/T1 pulse timing, MB full=8, MB FSM transition matrix, and L1DTLB reset state.

Delete or de-scope:

- Delete the black-box exact PLRU replacement expectation from the L1DTLB functional test plan.
- Delete/replace the "store triggers D-bit update" test intent; keep the TC-ID only if its expected behavior is changed to page fault/no writeback.
