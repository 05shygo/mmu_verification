# PTW Stage 5 SVA Gap Table

This table records Stage 5 source-side SVA items that are intentionally not
fully closed by assertions because the required source signal is not directly
observable in the bound RTL module or needs Stage 6 directed evidence.

| Gap ID | Requirement | Current Stage 5 Evidence | Open Reason | Close Condition |
| --- | --- | --- | --- | --- |
| ST5-GAP-001 | `PTW-SVA-PDE-007` no PDE update on leaf/fault/bus error/drop | `mmu_ptw_lsu_protocol_sva` checks bus error has no CHK writeback/PDE update; `mmu_pde_cache_sva` checks update level and clear behavior. | `PDE_cache` only sees already-filtered `mbuf_cache_upd`; it does not see raw leaf/page-fault/drop root cause. | Stage 6 directed tests must pair source monitor/ref/SB evidence with `mbuf_cache_upd==0` for leaf, page fault, bus error, abort and drop cases. |
| ST5-GAP-002 | `PTW-SVA-PDE-008` lookup/update same-cycle old-state | `mmu_pde_cache_sva` checks update allocates only on `*_entry_before_upd_hit` old-state miss and covers old-state hit/no-update. | Exact same-cycle lookup result for a colliding external request and update depends on a directed collision window; no standalone Stage 5 stimulus is added. | Stage 6/7 directed race test should hit lookup/update same tag and require source monitor PDE event plus SVA cover. |
| ST5-GAP-003 | `PTW-SVA-CHK-009/010` high reserved, RSW, G precise no-fault/data/tag semantics | `mmu_twu_chk_sva` covers observed RSW/high-reserved raw data and `mmu_ptw_top_sva` checks final refill bit layout. | CHK module has no explicit "reserved ignored" branch signal; source truth is final no-fault/refill compare. | Stage 6 raw PTE directed tests must prove no page fault for RSW/high reserved and bit-exact flg/global compare in source SB. |
| ST5-GAP-004 | `PTW-SVA-CHK-006` PFU special permission matrix | `mmu_twu_chk_sva` covers PFU entering CHK and checks common invalid/write-only/U-S/A/huge rules. | RTL does not expose a separate PFU permission formula; the current CHK logic uses the same raw signals and Stage 5 avoids inventing monitor-only state. | Stage 6 PFU directed tests must close PFU no-R/no-X/no-D behavior through source scoreboard. |
| ST5-GAP-005 | `PTW-SVA-MBUF-010/011/012` full abort matrix | `mmu_ptw_lsu_protocol_sva` checks abort no-create and outstanding-request drop shape; `mmu_ptw_top_sva` checks abort blocks normal refill. | Pre-existing exception-grant visibility and same-cycle abort/bus-error classification need scoreboard/drop classification from Stage 4 plus directed timing windows. | Stage 6/7 abort matrix tests must close late data, abort bus error, and pre-existing exception grant evidence. |
| ST5-GAP-006 | `PTW-SVA-MAEE-007/008/009` degrade no-lower-walk, huge-align-before-degrade, mid-walk MAEE sampling | `mmu_sysmap_sva` checks flag substitution, cross/no-cross page-size behavior and sysmap PA alignment; `mmu_twu_chk_sva` checks huge misalignment blocks CHK refill/CSR request. | No single Stage 5 bind sees all lower-level memory request count, sysmap FSM state and context-change sampling. | Stage 6/7 MAEE directed tests must combine source memory-request trace, source SB final page size/PPN/flg and SVA cover. |
| ST5-GAP-007 | `PTW-SVA-REG-*` internal refill/page/access register full payload hold | Partial evidence in `mmu_twu_chk_sva`, `mmu_pmp_twu_sva`, `mmu_ptw_top_sva` covers wait, priority and payload routes. | Stage 5 plan lists these as refill/exception register SVA, but the current stage scope did not add a new `mmu_arb`/register bind beyond top/TWU observable outputs. | Later SVA/report closure should either add dedicated register-level bind or mark source SB plus top SVA as sufficient evidence. |

Stage 5 did not use UVM monitor-only state as DUT functional input. All new SVA
modules bind to RTL-visible signals only.
